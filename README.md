# 🧮 Modern Calculator

A sleek, high-performance, and responsive **Calculator Application** engineered using HTML5, CSS3, and Vanilla JavaScript. Built with a focus on intuitive user experience, dynamic visual feedback, and seamless keyboard accessibility.


## ✨ Key Features

* **Core Arithmetic Operations:**
  * Addition (`+`)
  * Subtraction (`-`)
  * Multiplication (`×`)
  * Division (`÷`)
  * Modulo (`%`)
* **Real-Time Display Screen:**
  * Dual-line view showing current input and calculated results.
  * Automatic handling of decimal points and reset states.
* **Modern Aesthetic UI:**
  * Dark Midnight Violet theme with neon accents.
  * Glowing container border for a sharp layout.
  * Smooth micro-interactions and button hover animations.
* **Fully Responsive Design:**
  * Fluid grid layout optimized for mobile, tablet, and desktop screens.
    

## ⚡ Pro Capabilities & UX Enhancements

* **⌨️ Seamless Hardware Keyboard Integration:**
  * Full physical keyboard mapping for lightning-fast calculations.
  * Number keys (`0`-`9`) and standard math operators (`+`, `-`, `*`, `/`, `%`).
  * Instant execution with `Enter` or `=` keys.
  * Smart hotkeys: `Backspace` for quick backspacing and `Escape` (Esc) for instant screen clearing.
* **🎨 Next-Gen Visual Feedback:**
  * Tactile button press simulation with dynamic CSS depth effects.
  * Neon lighting transitions designed for high visibility and visual engagement.


## 🛠️ Tech Stack

* **HTML5:** Structured semantic markup for display and control layout.
* **CSS3:** Custom Grid layout, CSS Flexbox, and neon lighting animations.
* **JavaScript (ES6+):** Calculation logic, DOM updating, and event listeners for keyboard input.
